# E-Commerce Sales Analysis
This project analyzes e-commerce sales data using Excel and Power BI. It provides insights into sales, customers, products, and purchasing trends.
# Tools Used
Microsoft Excel
Microsoft Power BI
## Project Contents

- E-Commerce sales data in Excel
- Sales analysis and visualization in Power BI
- Interactive dashboard for analyzing sales performance
  ## Key Analysis

- Category-wise sales analysis
- City-wise sales analysis
- Product-wise sales analysis
- Customer-wise sales analysis
- Sales trend over time
- Category-wise sales share
- Interactive Power BI dashboard
  ## Project Objective

The objective of this project is to analyze e-commerce sales data and create an interactive dashboard to understand sales performance and identify useful business insights.
